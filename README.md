# HostelMate


Your hostel, handled.

Wardenly is a digital hostel management and assistance platform
designed to simplify everyday hostel life for students, wardens,
and hostel staff.

## Features

- Leaves & outings
- Mess management
- Complaints
- Notices
- Attendance
- Housekeeping

## Tech Stack

Frontend: React
Backend: Java + Spring Boot
Database: MySQL
